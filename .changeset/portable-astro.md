Adds support for moving server build output to another directory or machine without rebuilding.

The server code generated by `astro build` no longer contains absolute paths from the build
machine. You can build in one place and run the output in another, such as building in CI and
deploying the resulting `dist/` directory to a server, building on Windows and deploying on Linux,
or restoring cached build output across CI runs.

Keep `node_modules/` next to `dist/` when you deploy the build output. The `file` property of
imported Astro, Markdown, and MDX files, such as `AstroInstance.file` and `MarkdownInstance.file`,
still contains the absolute path from the build machine.
